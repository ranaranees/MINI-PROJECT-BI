# MINI-PROJECT-BI
Sales Performance Dashboard

Overview

An interactive sales dashboard built using Power BI to analyze sales performance and identify business trends.

Tools Used

* Microsoft Excel
* Power Query
* Power BI
* DAX

Key Features

* KPI cards for total sales, orders, quantity sold, and average order value.
* Sales analysis by product, city, date, and hour.
* Interactive slicers for filtering data.

Data Cleaning

Cleaned the dataset using Power Query by removing unnecessary columns, separating date and time, and correcting text formatting and data types.
