# MINI-PROJECT-BI
📊 Sales Performance Dashboard | Power BI Mini Project

1. Overview

This mini project focuses on cleaning, analyzing, and visualizing sales data using Microsoft Excel, Power Query, and Power BI to understand business performance and identify sales trends.

2. Aim

To develop an interactive Power BI dashboard that analyzes sales performance across products, cities, dates, and hours to generate meaningful business insights and support data-driven decision-making.

3. Objectives

* Clean and prepare raw sales data for analysis.
* Calculate key performance indicators (KPIs) using DAX.
* Identify top-performing products and cities.
* Analyze sales trends over time and across different hours.
* Build an interactive dashboard using charts and slicers.

4. Tools & Technologies

* Microsoft Excel: Data storage and initial preparation.
* Power Query: Data cleaning and transformation.
* Power BI Desktop: Dashboard development and visualization.
* DAX: Creating measures and calculating KPIs.

5. Data Cleaning & Preparation

* Removed unnecessary index columns.
* Separated order date and order time.
* Applied Proper Case formatting to text fields.
* Corrected column data types and formatted sales values.
* Removed the redundant Month column because the dataset contained December records in the reviewed data.

6. Key Performance Indicators

* Total Sales
* Total Orders
* Total Quantity Sold
* Average Order Value
* Total Products
* Average Selling Price

7. Dashboard Features

* Sales by Product: Compares revenue generated by different products.
* Sales by City: Identifies cities with higher sales.
* Sales Over Time: Examines changes in sales across dates.
* Sales by Hour: Highlights high-revenue hours.
* Quantity Sold by Product: Compares product sales volumes.
* Orders by City: Compares order counts across cities.
* Interactive Slicers: Filter results by city, product, and date.

8. Skills Demonstrated
